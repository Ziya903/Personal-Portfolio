# Personal Portfolio Website

A responsive personal portfolio website built using HTML, CSS, and JavaScript.

The website showcases my introduction, skills, projects, and contact section in a clean and simple design.

## 🚀 Features

- Responsive portfolio layout
- Home section with introduction
- About Me section
- Skills section
- Projects section
- GitHub project links
- Contact section
- Contact form validation using JavaScript
- Smooth scrolling navigation
- "Hire Me" button scrolls to the Contact section
- Form reset after successful validation

## ⚙️ JavaScript Functionality

JavaScript is used to add interaction to the website, including:

- Smooth section navigation
- Button click events
- Contact form validation
- Empty-field checking
- Success message
- Form reset
